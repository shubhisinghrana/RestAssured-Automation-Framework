# REST Assured API Automation Framework

A robust API testing framework built with **Java**, **REST Assured**, **TestNG**, and **Maven**. Designed for automated functional testing, assertion validation, and response parsing of RESTful Web Services.

---

## 🛠️ Tech Stack & Tools

* **Language:** Java 8+
* **API Library:** REST Assured
* **Test Runner / Framework:** TestNG
* **Build Tool:** Maven
* **Data Interchange:** JSON / Jackson Databind

---

## ⚙️ Features

* **Automated HTTP Methods:** Comprehensive test coverage for `GET`, `POST`, `PUT`, `DELETE` requests.
* **Payload Management:** Flexible request body generation using HashMaps and POJO serialization.
* **Assertions:** Deep validation of response status codes, headers, and JSON body elements using Hamcrest matchers.
* **Maven Integration:** Managed dependencies and seamless execution via `pom.xml`.
